# 🤖 Jarvis AI Assistant

An AI-powered voice assistant built with Python that can perform desktop automation, speech recognition, web search, and AI-powered conversations.

## 🚀 Features

- 🎤 Speech Recognition
- 🔊 Text-to-Speech
- 🌐 Open Websites
- 💻 Open Applications
- 🔍 Google Search
- 📺 YouTube Search
- 🤖 AI Chat (Gemini/OpenAI)
- 📝 Memory System
- 🌦️ Weather Updates
- 📰 News Updates

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- sounddevice
- Requests
- Gemini/OpenAI API
